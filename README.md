# Exercício módulo 36 — SQL

Exercícios de banco de dados com tabelas de funcionários e salários.

## Conteúdo

- Criação do banco `Empresa`, tabelas, chaves primárias e chave estrangeira.
- Inserção, consulta, atualização e exclusão de registros.
- Média salarial por cargo com `AVG` e `GROUP BY`.
- Consulta de nomes, salários e cargos com `INNER JOIN`.

## Como executar

Use MySQL 8.0.16 ou superior e um cliente SQL, como MySQL Workbench.

Execute `exercicio_modulo_36.sql` em um ambiente de estudos onde o banco `Empresa` ainda não exista. O arquivo reúne os quatro exercícios.

Como alternativa, execute os arquivos da pasta `sql/` na ordem: `01_criacao.sql`, `02_crud.sql`, `03_agrupamento.sql` e `04_juncao.sql`.

Escolha uma das duas formas de execução para evitar criar o banco e inserir os mesmos dados duas vezes. Os exemplos de CRUD incluem atualização e exclusão dos registros de demonstração.
